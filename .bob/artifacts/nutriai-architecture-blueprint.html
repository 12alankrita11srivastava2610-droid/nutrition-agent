📡 Key Data Flows
1
Chat Q&A: User types question → Flask /api/chat → Profile context + history injected into Granite prompt → Response streamed back as HTML
2
Meal Plan: User sets days → Profile pulled (TDEE, allergies, cuisine) → MEAL_PLAN_PROMPT built → Granite generates 7-day plan with macros + shopping list
3
Image Analysis: Image uploaded → Pillow preprocesses → Tesseract extracts text → Image type detected (food photo vs label) → Granite analyses nutrition
4
Adaptive Loop: User rates meal (1–5 ★) → Stored in profile.feedback_history → Next /api/suggestions call uses liked/disliked items in Granite prompt
5
Food Lookup: Query → Built-in DB → USDA API fallback → Nutritionix fallback → Nutrition card returned + Granite enrichment available
